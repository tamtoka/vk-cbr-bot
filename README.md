# Бот ВКонтакте с курсами Банка России

Домашняя работа VPd04, вариант 2. Бот принимает сообщения сообщества через Bots Long Poll и получает официальные курсы из [XML API Банка России](https://www.cbr.ru/development/sxml/). Для запросов к ЦБ дополнительный ключ не нужен.

| Кнопка | Что делает |
| --- | --- |
| **Курсы** | Показывает USD, EUR и CNY с датой действия курсов. |
| **Курс валюты** | Предлагает ввести код. Например, `JPY` покажет курс и номинал иены из таблицы ЦБ. |
| **Конвертер** | Предлагает ввести сумму и код. Например, `1000 JPY` пересчитывает сумму в рубли с учётом номинала. |

Курсы ЦБ используются для расчёта и могут отличаться от курсов обмена в банках. Буквенный код и сумму с кодом можно отправить сразу. `/start` показывает меню.

## Запуск

1. Создайте сообщество ВКонтакте или выберите отдельное тестовое сообщество. Включите сообщения и возможности ботов в настройках сообщества.
2. В разделе «Работа с API» настройте Long Poll и включите событие «Входящее сообщение» (`message_new`). Создайте ключ доступа сообщества с правами для сообщений и получения настроек Long Poll.
3. Создайте окружение с Python 3.11 или новее и заполните `.env`.

   ```bash
   python3 -m venv .venv
   .venv/bin/python -m pip install -r requirements.txt
   cp .env.example .env
   # Укажите VK_BOT_TOKEN в .env
   .venv/bin/python bot.py
   ```

   В Windows используйте `python -m venv .venv`, `Copy-Item .env.example .env` и `.venv\Scripts\python.exe`.

4. Отправьте `/start` в личные сообщения сообщества. Проверьте три кнопки, затем отправьте `JPY`, `1000 JPY` и неизвестный код `ZZZ`.

`cbr_api.py` обращается к API и разбирает XML. `bot.py` подключает VKBottle, обрабатывает ввод и формирует ответы. `.env` и `.venv` исключены из Git.

## Запуск на VPS с systemd

1. Скопируйте проект в `/opt/vk-cbr-bot`, создайте там `.venv` и установите зависимости из `requirements.txt`.
2. Создайте `/etc/vk-cbr-bot.env` с правами `0600` и укажите `VK_BOT_TOKEN`.
3. Установите службу и проверьте её статус.

   ```bash
   sudo install -m 644 deploy/vk-cbr-bot.service /etc/systemd/system/
   sudo systemctl daemon-reload
   sudo systemctl enable --now vk-cbr-bot.service
   sudo systemctl status vk-cbr-bot.service
   ```

Служба запускает бота под непривилегированным пользователем. Long Poll использует исходящие HTTPS-соединения, поэтому входящие порты для бота не требуются. Если это сообщество уже обслуживает другой бот, сначала согласуйте переключение.
